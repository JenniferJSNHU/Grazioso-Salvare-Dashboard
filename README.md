Grazioso Salvare Animal Shelter Dashboard
This project enhances the animal shelter dashboard originally developed in CS 340. The CS 499 enhancements improve the interface, application structure, record management, and security.
Sign In Instructions
Live Dashboard: https://grazioso-salvare-dashboard.onrender.com
1. Open the dashboard link in a web browser
2. Enter the staff username and password commented with the submission
3. Sign in and view the dashboard
The hosted dashboard does not require any software installation. The first load may take about a 1-2 minutes.
