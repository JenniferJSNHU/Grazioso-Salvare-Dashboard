# Grazioso Salvare Animal Shelter Dashboard

This project enhances the animal shelter dashboard originally developed in CS 340. The CS 499 enhancements improve the interface, application structure, record management, and security.

## Sign In Instructions

**Live Dashboard:** https://grazioso-salvare-dashboard.onrender.com

1. Click on the dashboard link
2. Enter the username and password from the submission comments
3. Sign in and access the dashboard

**Note:** Running the application locally requires Python dependencies, a MongoDB connection, and configured staff authentication environment variables. No software installation or additional configuration is required when accessing the hosted dashboard through the provided URL. The dashboard may take 1–2 minutes to load initially.
